## 3 条铁律（本手册立场）

1. **AI 是助手，不是作者** — 署名者必须真实贡献研究
2. **喂给 AI 的信息 = 可能泄露的信息** — 脱敏再传
3. **AI 输出必须人验** — 引用逐条核实，数据回到原始记录
