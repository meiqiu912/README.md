## 干货先行：新手写作的 7 个坑

1. **标题起得像工作总结** → 标题里必须有情绪钩子：好奇/焦虑/利益/反差/共鸣
2. **写完自己都不想点开就发** → 发前自测三问：标题想点吗？开头抓人吗？读完有收获吗？
3. **选题全凭灵感** → 建 50 个候选选题库，每天从库里挑 1 个写
4. **用 AI 写出 AI 味** → 问题不在 AI 在指令，好指令让 AI 用口语化有情绪的语言写
5. **模仿爆款只抄皮** → 要拆到"它戳中了读者什么情绪、结构怎么排的"
6. **闷头写不看数据** → 数据是免费的编辑老师，每周复盘
7. **只输出不沉淀人设** → 变现靠信任，每篇让读者记住你是谁
