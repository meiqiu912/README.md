## 7 步框架一览

| 步骤 | 内容 | 时间 |

| 第0步 | 准备工作：GSC + GA4 + 域名验证 | 1-2天 |

## 核心心法
- SEO 通常 1-3 个月见起色，6-12 个月见真章，**坚持更新+坚持改进是唯一捷径**
- 新手选词标准：月搜索量 200-2000、竞争难度 ≤5、带商业意图
- 别碰红线：买低质外链、垃圾评论塞链接、AI 批量内容农场
